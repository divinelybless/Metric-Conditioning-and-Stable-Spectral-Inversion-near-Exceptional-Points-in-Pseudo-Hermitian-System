# Metric Conditioning and Stable Spectral Inversion near Exceptional Points in Pseudo-Hermitian Systems

**Metric Conditioning and Stable Spectral Inversion near Exceptional Points in Pseudo-Hermitian Systems**

## Main result

For the coupled three-level pseudo-Hermitian family studied in the manuscript, the optimized compatible-metric condition number obeys

```text
kappa_*(A_epsilon) = (8/epsilon^2) [1 + o(1)]
```

as the exceptional point is approached, while the Euclidean inverse remains uniformly stable. The manuscript also develops a growing-dimensional coupled family showing that the separation between metric ill-conditioning and inverse stability persists with system size.

## Reproducing the numerical results

Create a Python environment and install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Then run the scripts in `code/` from the repository root. The scripts verify the two-level and three-level calculations, the optimized-metric asymptotics, the growing coupled family, and the inversion-stability bounds used in the manuscript.
