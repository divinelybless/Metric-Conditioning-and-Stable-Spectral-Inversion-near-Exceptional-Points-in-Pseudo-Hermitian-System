# Metric Conditioning and Stable Spectral Inversion near Exceptional Points in Pseudo-Hermitian Systems

**Metric Conditioning and Stable Spectral Inversion near Exceptional Points in Pseudo-Hermitian Systems**

## Main result

For the coupled three-level pseudo-Hermitian family studied in the manuscript,

```text
kappa_*(A_epsilon) = (8/epsilon^2) [1 + o(1)]
```

as the exceptional point is approached, while the Euclidean inverse remains uniformly stable. A growing-dimensional coupled family shows that this separation between metric ill-conditioning and inverse stability persists with system size.

## Repository structure

- `manuscript/main.tex` — manuscript build driver
- `manuscript/sections/` — LaTeX manuscript sections
- `manuscript/references_manual.tex` — references used by the manuscript
- `code/reproduce_figures.py` — numerical checks and generation of the five manuscript figures
- `requirements.txt` — Python dependencies

The PDF figures are generated locally into `manuscript/figures/`; they are not stored as opaque binary source files in the repository.

## Reproducing the figures and checks

From the repository root:

```bash
python -m pip install -r requirements.txt
python code/reproduce_figures.py
```

The script generates the five figures required by the manuscript and checks the key two-level, three-level, and growing-dimensional bounds.

## Building the manuscript

After generating the figures:

```bash
cd manuscript
pdflatex main.tex
pdflatex main.tex
```
